# Our mBot2 Programming Activities

## Screen Display Projects

In these activities, we learned how to control the **CyberPi** screen on our *mBot2* using Python commands to display customized text.

1. **Display Your Name:** Uses the `cyberpi.console.print("Mert")` command to print my first name on the screen.
2. **Surname and Grade on Separate Lines:** Uses `cyberpi.console.println("Ozan")` followed by `cyberpi.console.println("Grade 10")` so each piece of text automatically moves to a new line.
3. **Clear the mBot2 Screen:** Uses `cyberpi.console.clear()` to erase all previous text and reset the display before showing new information.
4. **Change Font Size:** Uses `cyberpi.display.show_label("Hello", 24, "center")` where the number `24` adjusts the text size on the screen.

## LED Control Project

- **RGB LED Control (`cyberpi.led.on()`):** Programs the onboard RGB LEDs to light up in **red** `(255, 0, 0)`, **green** `(0, 255, 0)`, and **blue** `(0, 0, 255)` with short pauses in between.
